## 处理摘要（后写，非原始回复）

按已审核的 `charhash-v1` 方案实现字符 unigram/bigram 特征。为防止“同一实现生成测试期望”的自证，测试单独用 SHA-256 手算特征编码：`ab` 的三个桶分别是 249、138、68，权重 1、1、2；还在独立 Java 进程中校验完整 1,024 字节向量的 SHA-256 摘要。

CPU 模拟作为单独模块返回校验值，不参与向量计算；这保证调整模拟工作量不改变向量。向量编码固定大端 float，零向量余弦为 0，同分 Top-K 按文档 ID 升序。这些行为来自已提交的设计，并非后来新增题目要求。
